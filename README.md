# 🧮 Grade Calculator

### A Web-Based Weighted Grade Calculation Tool

**Web Development | Mathematical Logic | User Input Processing | 2026**

A web-based grade calculator designed to help students calculate their overall academic grades based on individual assessment scores and their corresponding weightings.

The application simplifies weighted grade calculations by providing an interactive tool for students to estimate their overall module performance.

---

## 📌 Project Overview

University modules often consist of multiple assessments, such as coursework, assignments, quizzes and examinations, each contributing a different percentage towards the final grade.

Calculating the overall result manually can become confusing, particularly when assessment weightings vary.

The Grade Calculator was developed to simplify this process by allowing users to enter their assessment marks and weightings, then calculate their overall grade.

The project demonstrates how mathematical formulas and programming logic can be applied to create a practical academic tool.

## ✨ Key Features

### 1. Assessment Score Input

Users can enter marks obtained for different assessments within a module.

These may include coursework, examinations, assignments or quizzes.

### 2. Custom Assessment Weightings

The calculator supports assessments that contribute different percentages towards the overall module grade.

For example:

- Coursework 1 — 30%
- Coursework 2 — 30%
- Final Examination — 40%

### 3. Weighted Grade Calculation

The application calculates each assessment's contribution according to its assigned weighting.

This provides a more accurate overall grade than simply averaging all assessment marks equally.

### 4. Overall Grade Display

The calculated result is presented to the user, allowing them to understand their overall academic performance.

### 5. Interactive User Interface

The web interface allows users to enter assessment information and obtain calculated results without manually performing the mathematical operations.

## 🧠 Calculation Method

The calculator applies the weighted average formula:

**Overall Grade = Σ (Assessment Mark × Assessment Weight / 100)**

Where:

- Assessment Mark represents the score achieved.
- Assessment Weight represents the percentage contribution.
- Σ represents the sum of all weighted assessment contributions.

### Example Calculation

Suppose a module contains three assessments:

| Assessment | Mark | Weight |
|---|---:|---:|
| Coursework 1 | 75% | 30% |
| Coursework 2 | 80% | 30% |
| Final Examination | 70% | 40% |

**Step 1 — Calculate weighted contributions**

Coursework 1:

75 × 0.30 = 22.5

Coursework 2:

80 × 0.30 = 24.0

Final Examination:

70 × 0.40 = 28.0

**Step 2 — Add the contributions**

22.5 + 24.0 + 28.0 = **74.5%**

**Final Overall Grade: 74.5%**

This example assumes that the assessment weightings total 100%.
